# AutoForge Engineering Studio

Browser-based automotive CAD, simulation and engineering platform: parametric B-rep modelling on Open CASCADE,
assemblies with mates and motion studies, CalculiX simulation, associative drawings with GD&T checks, a sourced
component library, engineering calculators, an accountable AI assistant and private collaboration rooms.

Every engineering result is traceable to the engine or source that produced it. Capabilities that need an external
solver or service (for example CFD) are labelled as such and never simulated. See the live
[feature status](docs/feature-status.md).

## Architecture at a glance

- `apps/web` — Next.js 16 / React 19 / React Three Fiber client (workbenches, sketch editor, viewers).
- `services/api` — FastAPI service: OCCT kernel worker pool, sketch solver, document revisions, simulation job queue
  and worker (Gmsh + CalculiX), drawings, catalog, collaboration, AI assistant, security.
- `infra` — Dockerfiles, docker compose stack (Caddy TLS, Postgres, Redis, S3-compatible storage), backup/restore.
- `docs` — [architecture](docs/architecture.md), [ADRs](docs/adr), [security](docs/security.md),
  [runbooks](docs/runbooks), [user guide](docs/user-guide.md), [file formats](docs/file-formats.md),
  [GD&T](docs/gdt.md), [simulation validation](docs/validation/simulation-benchmarks.md), [backlog](docs/backlog.md).

## Run it

Production-like stack (TLS, S3 storage, SMTP):

    cp .env.example .env        # fill in the REQUIRED values
    docker compose -f infra/docker-compose.yml --env-file .env up -d --build
    # local evaluation with a mail catcher: add --profile local-mail and SMTP_HOST=mail SMTP_PORT=1025 SMTP_STARTTLS=false

Development:

    # prerequisites: Python 3.12+, Node 22, Postgres 16, Redis 7 (optional), CalculiX (ccx) for simulations
    cd services/api && python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt
    python -m autoforge.cli migrate && python -m autoforge.cli seed
    uvicorn autoforge.api.main:create_app --factory --port 8000 &   # API
    python -m autoforge.jobs.worker &                                # simulation/email worker
    cd ../../apps/web && npm ci && npm run dev                       # http://localhost:3000
